# Проверки изменений редактора — 2026-11-05

Среда: Go 1.27.3, Node 24.22.1, Chromium. Исходная ветка: feat/knowledge-base, коммит 9d93c181.

- `npm run build` — успешно. Сохраняется существующее предупреждение сборщика об eval внутри htmx; выполнение eval в htmx отключено настройкой приложения.
- `GOMAXPROCS=4 go test -race -p 4 ./...` — успешно, включая границы паролей, валидацию цвета/размеров/видео, сохранение и публикацию защищённого медиа.
- `go vet ./...` — успешно.
- `npm run test:e2e` — 15 пройдено. Включает исходные сценарии учётных записей/конфликтов/поиска и новые сценарии DOCX, вставки Word HTML, публикации и повторного открытия, объединённых ячеек, предупреждения о недоступном видео, закреплённой панели на настольном и мобильном экране, воспроизведения загруженного видео и недоступности медиа для гостей.

Независимое ревью выявило два важных дефекта: массив ширин объединённой ячейки не соответствовал colspan, а локальное видео из буфера могло исчезнуть без предупреждения. Оба воспроизведены отдельными браузерными тестами до исправления; после исправления весь набор проходит.

Осталось несущественное замечание: проверка MIME `video/ogg` не используется, поскольку Go распознаёт Ogg как `application/ogg`. Загрузка файлов в интерфейсе и документации ограничена MP4/WebM; внешние ссылки воспроизводятся по возможностям браузера.

Первый общий браузерный запуск имел один таймаут на сценарии учётных записей при одновременной первичной компиляции race-сборки. Повторный последовательный запуск проходит. Первый race-запуск пересёкся с правкой тестового файла и был повторён после завершения изменений. Итоговые результаты выше относятся к полным успешным запускам.

Docker/ingress и нагрузочные проверки не повторялись: схемы БД, конфигурация ingress и предел запроса 12 МиБ не менялись. Ограничения импорта и инструкция проверки на ПК описаны в ../editor-upgrades.md.
