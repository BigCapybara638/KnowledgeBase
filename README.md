# KnowledgeBase

Внутренняя база знаний на Go и SQLite: категории, карточки, постоянные ссылки, учётные записи с выдачей администратором, визуальный редактор Tiptap с таблицами и изображениями, личные черновики и полнотекстовый поиск.

Приложение постоянно работает одним контейнером. SQLite встроена, Node.js нужен только для сборки. Изменения публикуются с проверкой версии; конфликт сохраняет личный черновик. Истории опубликованных версий и онлайн-соавторства нет.

## Развёртывание

1. Соберите образ: `docker build -t knowledgebase:local .`.
2. В отдельную папку, например `/opt/knowledgebase`, скопируйте `deploy/compose.yaml`, а `deploy/.env.example` — как `.env`. Укажите настоящий HTTPS-домен.
3. Подготовьте `data`/`backups` с владельцем 65532:65532 и создайте внешнюю сеть `knowledgebase-ingress`.
4. Создайте первого администратора через stdin **до** запуска сервера, затем выполните `docker compose up -d`.
5. Подключите существующий Nginx **1.27.3+** из его Compose-проекта к этой сети и добавьте отдельный виртуальный хост базы. Второй Nginx не нужен, порты хоста у базы не публикуются.

Точные команды, безопасный ввод пароля, настройка Nginx, обновление и восстановление: **[docs/operations.md](docs/operations.md)**. Не заменяйте действующий Compose Nginx целиком примерами из этого репозитория.

## Разработка и проверки

Go 1.27.3, Node.js 24 LTS и sqlc 1.30.0. Используйте существующий checkout; отдельный worktree для облачной задачи не требуется.

```sh
npm ci
make generate
make build
make verify
```

Playwright использует установленный `/usr/bin/chromium`, если он есть, либо свой браузер (`npx playwright install --with-deps chromium`). `PLAYWRIGHT_CHROMIUM_EXECUTABLE` переопределяет путь. Браузерные тесты создают временную БД и тестовые записи, не данные приложения.

`make test-integration` проверяет два одноразовых Compose-проекта через HTTPS, существующий клиентский маршрут и смену IP базы без перезапуска Nginx. Требует Docker и OpenSSL; образ `knowledgebase:test` предварительно собирается из этого checkout.

Контейнер ограничен 768 МиБ, Go GC — 512 МиБ; общий бюджет решения с добавочным расходом ingress — до 1 ГБ. В облачной проверке 5000 статей / 50 читателей / 5 авторов за 600 секунд пик добавленного расхода составил 250.13 МБ, ошибок и OOM не было. Пределы доказательств и полный отчёт: [docs/validation.md](docs/validation.md).

## Редактор и оформление

Тёмная тема Axentris, локальный Inter, импорт `.docx`, цвета текста/ячеек, размеры таблиц и видео: [инструкция и ограничения](docs/editor-upgrades.md).

Для запуска на ПК через Docker: `docker compose -f conpose-local.yaml up -d --build`, затем http://127.0.0.1:8080. При первом запуске сначала создайте администратора: [локальный Compose и диагностика входа](docs/operations.md#локально-через-docker-compose).
